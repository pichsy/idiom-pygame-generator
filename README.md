# 成语闯关生成器 (Idiom Level Generator)

这是一个基于 Python 的成语接龙/填字游戏关卡生成器。它使用回溯算法在 10x10 (可配置) 的网格中自动生成相互连接的成语布局，并支持可视化预览。

## 📖 项目简介
本项目主要用于生成“成语消消乐”、“成语填字”等游戏的关卡数据。核心算法能够确保生成的成语在网格中正确交叉连接，并自动处理边界检测和冲突避免。项目还包含一个简单的 GUI 工具，方便开发者快速预览生成效果并获取关卡数据。

## ✨ 功能特性
- **智能生成**: 基于回溯算法（Backtracking），确保成语首尾/中间字符正确衔接。
- **随机性**: 每次生成均为随机布局，保证关卡的多样性。
- **题目挖空**: 自动将部分汉字标记为“待填空”状态（用 `[ ]` 包裹，例如 `[龙]`），直接可用于游戏逻辑。
- **GUI 预览工具**: 提供 Tkinter 界面，支持实时查看生成结果。
- **数据导出**: 支持一键复制生成的二维数组 JSON 数据，方便集成到前端游戏引擎（Cocos Creator, Unity, Web 等）。

## 🚀 快速开始

### 环境要求
- Python 3.x
- Tkinter (Python 标准库，通常默认安装)

### 1. 启动可视化生成器 (推荐)
通过 GUI 界面直观地查看生成的关卡布局：

```bash
cd idiom-pygame
python3 gui_app.py
```

**操作说明**:
- 点击 **"换一个 (Refresh)"**: 立即生成一个新的 10x10 成语关卡。
- 点击 **"复制 JSON (Copy)"**: 将当前关卡的二维数组数据复制到剪贴板，格式如下：
  ```json
  [
    ["", "", "一", "马", "当", "先", "", "", "", ""],
    ["", "", "", "", "", "礼", "", "", "", ""],
    ...
  ]
  ```
  其中 `""` 表示空位，`"字"` 表示显示的字，`"[字]"` 表示被挖空的字。

### 2. 命令行运行 (API 模式)
如果你想在后端或批处理中生成数据，可以直接运行核心脚本：

```bash
python3 idiom-pygame/generate_level.py
```
程序会将生成的 JSON 数据打印到标准输出 (stdout)。

## ⚙️ 配置说明
在 `generate_level.py` 或 `gui_app.py` 中，你可以修改 `IdiomGenerator` 的初始化参数来调整生成逻辑：

```python
# x_block_num: 网格宽度
# y_block_num: 网格高度
# idiom_count: 期望生成的成语数量
generator = IdiomGenerator(x_block_num=10, y_block_num=10, idiom_count=6)
```

## 🛠️ 算法原理
1. **初始化**: 从 `simple.json` 中随机选取一个简单的成语作为“种子”，放置在网格中心附近。
2. **扩展**: 遍历已放置成语的每一个字符，在 `all.json` 中查找包含该字符的其他成语。
3. **回溯尝试**: 尝试将新成语在垂直/水平方向放置，如果检测到冲突（边界溢出、与其他成语重叠但字符不匹配等），则回溯尝试下一个候选词。
4. **居中与挖空**: 生成完成后，将整个布局居中，并随机隐藏部分字符作为题目。
